# 準1級 語彙ドリル (vocab-drill)

英検準1級の語彙問題集『英検準1級 語彙問題 完全制覇』を再現した、ブラウザで動く学習アプリです。
単一の `index.html` で完結し、インストール不要。スマホのホーム画面に追加すればアプリのように使えます（PWA対応）。

## 特長

- **問題演習**：4択の語彙問題（短文・会話文）を出題。解答後に各選択肢の意味を確認できます
- **今日のノルマ**：1日の目標問題数を設定し、進捗バーで達成状況を表示
- **出題の絞り込み**：問題の種類・番号範囲を指定、番号順／ランダム、未解答を優先
- **間違いストック**：間違えた問題や📌を付けた問題を貯めて、あとでまとめて復習
- **単語帳**：問題文や選択肢の単語を★で登録し、意味をメモ。発音もクリックで確認
- **読み上げ**：ブラウザの音声合成で問題文を自動読み上げ（速度・声・会話A/Bの声・空欄の読み方を設定可）
- **記録**：直近30日の日別解答数（正解／不正解）、種類別の正答率をグラフ表示
- **キーボード操作**：Enterで次へ、R／*で再読み上げ など
- **ダークモード**：OS設定に自動追従

## 使い方

1. GitHub Pages などで公開した `index.html` をブラウザで開く（ローカルで `index.html` を開いてもOK）
2. 「ホーム」で種類・範囲・順序を選んで **スタート**
3. 解答後、選択肢の意味を確認し「次へ」
4. 間違えた問題は「間違い」タブから復習

学習記録・単語帳・設定はブラウザの `localStorage` に保存されます。
「設定」→「データ」から、バックアップの保存／読み込み／リセットができます。
